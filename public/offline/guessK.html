Intro Stats Classroom Demo

Guess the Hidden K

I will submit a secret K under someone's watch, then show the class a sample of generated numbers without revealing K until the end.

Rules

  1. Score = 100 number of numbers requested + |guessed K - actual K|
  2. Each draw is independent, so the same number can appear more than once.
  3. Each group can request as many or as few numbers as they want, but may submit only one guess.

Round Setup

Starting a new round updates the hidden K, clears the numbers, and hides the answer again.

Click the field and type the new value for K. The screen will show one dot per digit while keeping the actual value hidden.

Generate Numbers

Numbers are displayed in numerical order automatically, and repeated values are allowed.
