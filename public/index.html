Intro Stats Classroom Game

Guess the Hidden K

Student groups request independent draws from 1 to a hidden K, weigh sample size against accuracy, and lock in a single guess while the instructor tracks every decision live.

Rules

  1. Score = 100 number of numbers requested + |guessed K - actual K|
  2. Each draw is independent, so the same number can appear more than once.
  3. Each group can request as many or as few numbers as they want, but may submit only one guess per round.
